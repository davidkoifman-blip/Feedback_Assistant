# Feedback Assistant

ИИ-ассистент для Moodle, который помогает преподавателю писать обратную связь по письменным работам студентов.

Проект ИТМО, осень 2026. Репозиторий публичный: [Feedback_Assistant](https://github.com/davidkoifman-blip/Feedback_Assistant).

## О чём проект

Преподаватель загружает формулировку задания, рубрику и работу студента: эссе, отчёт в PDF или DOC, кейс, проектное задание или ответ на открытый вопрос. Агент разбирает текст по критериям и собирает черновик:

- сильные стороны;
- замечания по каждому критерию;
- рекомендации и следующий шаг;
- проект баллов по рубрике.

Итоговый комментарий правит и утверждает преподаватель. Система сама не ставит финальную оценку и сама не отправляет текст студенту.

## Ожидаемый результат MVP

- агент подключается к заданию Moodle или работает через отдельный интерфейс;
- можно загрузить задание, рубрику и работу студента;
- черновик обратной связи собирается по структуре выше;
- комментарий по возможности привязан к фрагменту работы;
- преподаватель может принять, поправить или отклонить черновик;
- баллы по критериям не публикуются в журнал автоматически;
- основной язык — русский, английский желателен;
- есть описание ограничений, защиты данных и принципа human-in-the-loop.

Подробная постановка — в [дизайн-документе](docs/ml_system_design_doc.md).

## Ограничения

- в языковую модель не передаются персональные данные студентов;
- для разработки используются обезличенные работы и тестовые рубрики;
- есть легаси-прототип 2025 года, от него отталкиваемся.

## Установка

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pre-commit install
```

После `pre-commit install` проверки запускаются сами на `git commit`.

## Линтер и форматтер

В проекте используется [Ruff](https://docs.astral.sh/ruff/): он и проверяет код, и приводит его к одному стилю. Настройки лежат в `pyproject.toml`.

Проверить код:

```bash
ruff check .
```

Поправить то, что можно автоматически:

```bash
ruff check . --fix
```

Отформатировать:

```bash
ruff format .
```

Прогнать все хуки вручную:

```bash
pre-commit run --all-files
```

Если Ruff находит ошибку или неверный формат, коммит не пройдёт, пока файл не исправишь.

## Как сдаём домашние работы

Каждое ДЗ идёт отдельной веткой `hw_n` и pull request в `main`.

```bash
git checkout -b hw_1
git add .
git commit -m "Homework 1: repo setup and design doc"
git push -u origin hw_1
```

В reviewers добавляются ментор и кросс-ревьюеры. В `main` мержим только после ревью.
